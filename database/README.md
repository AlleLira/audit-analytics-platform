# Database

Esta pasta contém todos os scripts SQL utilizados na implementação do banco de dados da Audit Analytics Platform.

## Estrutura

- **01_database**: criação do banco de dados.
- **02_tables**: criação das tabelas.
- **03_constraints**: chaves primárias, estrangeiras e restrições.
- **04_indexes**: índices para otimização de consultas.
- **05_views**: views analíticas.
- **06_procedures**: stored procedures.
- **07_seed**: carga inicial de dados.
- **08_tests**: scripts de validação e testes.
